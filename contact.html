Contact & corrections

Help improve RankMyIncome by reporting a data discrepancy, broken page, translation or accessibility problem.

Report an issue

Use the RankMyIncome GitHub issue tracker. A GitHub account is required to submit an issue. Reports are public, so please do not include your personal income, identity documents or private account information.

What to include

Include the page URL, selected country, language, browser and a description of what went wrong. For a data correction, link to the relevant WID series and year. You can demonstrate a calculation issue with an invented example income.

Data and methodology

RankMyIncome is independent of WID.world. See our methodology for income definitions, source links and limitations.
